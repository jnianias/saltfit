# SALTFit

SALTFit is an independent Python package for fitting Semi-Analytical Line Transfer (SALT -- see [Carr et al. 2023](https://iopscience.iop.org/article/10.3847/1538-4357/acd331)) models to astronomical spectra with an intuitive, object-oriented API and Markov chain
Monte Carlo (MCMC) methods.

## Project status

SALTFit is at an early stage of development and should be considered unstable.
The public API and SALT integration are available but still evolving. The
repository contains the package implementation, development tooling,
documentation, and tests.

## Installation

SALTFit is currently installed directly from its Git repository. Install it
with pip:

```bash
python3 -m pip install "saltfit @ git+https://github.com/jnianias/saltfit.git@v0.1.0a1"
```

Or add it to a project managed by [uv](https://docs.astral.sh/uv/):

```bash
uv add "saltfit @ git+https://github.com/jnianias/saltfit.git@v0.1.0a1"
```

## Fit a SALT model

SALTFit uses a separately installed and built checkout of the official
[SALT implementation](https://github.com/CodyCarr/SALT). It does not bundle or
distribute the SALT model. Configure its location once in your shell:

```bash
export SALTFIT_SALT_PATH=/path/to/SALT
```

To configure this path automatically in future Bash sessions, add the export to
your `~/.bashrc` file, then reload it:

```bash
echo 'export SALTFIT_SALT_PATH=/path/to/SALT' >> ~/.bashrc
source ~/.bashrc
```

The path must contain `python/run_salt.py` and the shared library generated by
`make`: `libsalt.so` on Linux or `libsalt.dylib` on macOS.

### Prepare the spectrum

SALT fits a spectrum relative to a unit continuum. Before creating a
`Spectrum`, fit a continuum using a method appropriate to your data, then
divide the observed flux and its one-sigma uncertainty by the continuum model:

$$
f_{\mathrm{normalized}} = \frac{f_{\mathrm{observed}}}{C},
\qquad
\sigma_{\mathrm{normalized}} = \frac{\sigma_{\mathrm{observed}}}{C}.
$$

Here $C$ is the continuum model evaluated at each spectral sample. SALTFit does
not fit or normalize continua itself, because continuum modelling choices are
specific to the observation and science case.

This example fits an outflowing P-Cygni profile for one transition. Replace the three
normalized arrays with your velocity-space spectrum and choose scientifically
appropriate initial values and priors for your data.

```python
import numpy as np

from saltfit import SALTModel, Spectrum


spectrum = Spectrum(
    velocity=np.array([-200.0, 0.0, 200.0]),  # km/s
    flux=np.array([0.9, 1.0, 1.1]),
    uncertainty=np.array([0.05, 0.05, 0.05]),
)
profile_parameters = {
    "absorption_parameters": {
        "abs_waves": [2382.04],
        "abs_osc_strs": [0.32],
        "abs_ein": [2.69e9],
    },
    "emission_parameters": {
        "em_waves": [2382.04],
        "emitted_waves": [2382.04],
        "em_osc_strs": [0.32],
        "em_ein": [2.69e9],
        "res": [True],
        "fluor": [False],
        "p_r": [1.0],
        "p_f": [0.0],
        "line_num": [1],
    },
    "blending_parameters": {
        "blended_waves": [[0.0]],
        "blended_osc_strs": [[0.0]],
        "blended_abs_ein": [[0.0]],
        "blended_fluor": [[False]],
        "blended_p_r": [[0.0]],
        "blended_p_f": [[[0.0]]],
        "blended_flour_waves": [[[0.0]]],
        "blending": [False],
    },
    "observing_parameters": {"v_ap": 50.0, "APERTURE": True},
    "miscellaneous_parameters": {"OCCULTATION": True, "Sobolev": True, "SW": 100.0},
}
initial_values = {
    "alpha": np.pi / 2.0,
    "psi": 0.0,
    "gamma": 1.0,
    "tau": 0.1,
    "v_0": 25.0,
    "v_w": 500.0,
    "v_b": 10.0,
    "f_c": 1.0,
    "k": 0.0,
    "delta": 1.5,
}
bounds = {
    "alpha": (0.01, np.pi),
    "psi": (-np.pi / 2.0, np.pi / 2.0),
    "gamma": (0.1, 3.0),
    "tau": (0.001, 10.0),
    "v_0": (1.0, 200.0),
    "v_w": (50.0, 1_500.0),
    "v_b": (0.0, 100.0),
    "f_c": (0.0, 1.0),
    "k": (0.0, 3.0),
    "delta": (0.1, 3.0),
}
model = SALTModel(
    lam_ref=2382.04,
    profile_type="pcygni",
    profile_parameters=profile_parameters,
    initial_values=initial_values,
    bounds=bounds,
    flow="outflow",
)
result = model.fit_to(spectrum, n_steps=1_000, n_walkers=24)
best_fit = result.median_parameters()
```

Save the complete fit archive—including the model configuration, the exact
spectrum used, and the MCMC result—to one HDF5 file by passing the output
filepath:

```python
result.write_hdf5("results/my-fit.h5")
```

Load the saved fit later to inspect the result and input spectrum without
loading SALT. Recreate a runnable model from its saved configuration with
`load_salt_model`; pass `salt_path` to use a different local SALT checkout.

```python
from saltfit import load_fit, load_salt_model

saved_fit = load_fit("results/my-fit.h5")
saved_spectrum = saved_fit.spectrum
saved_model = saved_fit.build_model()
```

`load_salt_model("results/my-fit.h5", salt_path="/path/to/SALT")` is a
convenience for loading just the runnable model, optionally from another local
SALT checkout.

`SALTModel.fit_to()` uses [emcee](https://emcee.readthedocs.io/) to sample a
normalized independent-Gaussian likelihood with the `Spectrum` uncertainties.
The `tqdm` dependency is installed automatically, so `progress=True` can be
used to display a progress bar during sampling.
`SALTModel(salt_path="/path/to/SALT", ...)` may be used instead of the
environment variable; an explicit `salt_path` takes precedence.

The outflow model additionally samples `v_b`, the Doppler parameter for thermal
and microturbulent broadening. For inflows, omit `v_b` and pass `flow="inflow"`;
both flow types use the nested `profile_parameters` layout shown above. Consult
the [official SALT documentation](https://github.com/CodyCarr/SALT) for complete
model-specific configuration and citation guidance.

### Systemic absorption

To fit absorption centered at systemic velocity alongside the SALT profile, add
a Gaussian component by setting `systemic_absorption=True`. Add its standard
deviation in km/s and continuum-flux depth to both fitted-parameter mappings:

```python
initial_values |= {
    "systemic_absorption_sigma": 50.0,
    "systemic_absorption_depth": 0.2,
}
bounds |= {
    "systemic_absorption_sigma": (1.0, 300.0),
    "systemic_absorption_depth": (0.0, 1.0),
}
model = SALTModel(
    lam_ref=2382.04,
    profile_type="pcygni",
    profile_parameters=profile_parameters,
    initial_values=initial_values,
    bounds=bounds,
    flow="outflow",
    systemic_absorption=True,
)
```

The component subtracts $d \exp[-v^2 / (2\sigma^2)]$ from the SALT flux,
where $d$ is `systemic_absorption_depth` and $\sigma$ is
`systemic_absorption_sigma`. Its centroid is fixed at $v = 0$ km/s; $\sigma$
must be positive and $d$ is constrained to $[0, 1]$.

## Development

SALTFit is developed with [uv](https://docs.astral.sh/uv/). Python 3.13 is the
current development version, and Python 3.11 to 3.14 are currently
targeted for support.

Create the development environment and install the development dependencies:

```bash
uv sync --all-groups
```

Run the checks used by continuous integration:

```bash
uv run ruff format --check .
uv run ruff check .
uv run pytest
uv build
```

### Performance benchmarks

Performance benchmarks are opt-in because they require a locally built SALT
checkout and can vary with compiler, CPU, and OpenMP configuration. Install the
development dependencies, set `SALTFIT_SALT_PATH`, then run the full
integration test file:

```bash
uv run pytest -m integration tests/test_performance.py
```

To run only the timing benchmarks:

```bash
uv run pytest -m integration tests/test_performance.py --benchmark-only
```

The integration suite checks both inflow and outflow model evaluation, finite
and deterministic output, parameter sensitivity, posterior evaluation, and a
short MCMC run. The benchmark subset measures the two hot paths used by MCMC:
one SALT model evaluation and one complete log-probability evaluation. Run it
before and after changes and compare the reported medians on the same machine.
The normal test suite excludes these tests and remains suitable for CI without
SALT.

To apply Ruff's formatting locally:

```bash
uv run ruff format .
```
